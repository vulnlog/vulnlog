Motivation::
// Why this particular decomposition into building blocks? State the driving structure and rationale.
Vulnlog is decomposed into three building blocks that mirror its build modules: `cli-app` (the command-line entry point used by engineers), `gradle-plugin` (the entry point for build tools and CI pipelines), and `lib` (the core library holding the analysis logic). Both entry points delegate to `lib`, which reads the Vulnlog YAML file (the single source of truth) and produces the generated artifacts: a vulnerability report, SCA suppression files and the planned VEX files. The internal structure of `lib` is detailed at Level 2.
