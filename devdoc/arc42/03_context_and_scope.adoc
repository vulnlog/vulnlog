[[section-context-and-scope]]
== Context and Scope

=== Business Context

image::Vulnlog-Context-View-Business.drawio.svg[alt="Business context view of Vulnlog with connected systems."]

[options="header",cols="1,2"]
|===
|Neighbour |Description

|Engineer
|A software or security engineer (maintainer of the software project). They analyse the scanner reports and record the analysis in the Vulnlog YAML file. Engineers run the Vulnlog CLI application.

|Build Tool and CI Pipeline
|They run Vulnlog to generate the artefacts.

|Product Manager, Product Owner and Support
|They need to know which vulnerabilities affect the software project. They plan upcoming releases and answer customer inquiries.

|Customer and User
|They use the software project. They need to know whether their software is at risk and when a fixed version is available.

|Security Team
|An in-house or external team. They monitor the risk of the software in use.

|Software Composition Analysis (SCA) Scanner
|Scans the software project for known vulnerabilities and reports them. Some scanners read the suppression files generated by Vulnlog.

| Software Composition Analysis (SCA) Platform
| A central monitoring platform such as OWASP Dependency-Track. It consumes Software Bills of Materials (SBOMs) and VEX documents. Vulnlog generates the VEX documents.

|Web Server
|Hosts the reports generated by Vulnlog.

|===
